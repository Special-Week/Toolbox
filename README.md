## 构建与运行

在项目根目录执行命令。需要支持 Rust 2024 Edition 的 Rust 工具链，以及匹配的本机链接器；Windows 使用 MSVC 工具链时需具备相应的 C++ 构建工具和 Windows SDK。

项目名为 **Toolbox**，Cargo 包名为 `toolbox`，可执行目标名为 `Toolbox`。依赖版本由 `Cargo.lock` 固定。

开发运行：

```powershell
cargo run --locked --bin Toolbox
```

发布模式运行或构建：

```powershell
cargo run --locked --release --bin Toolbox
cargo build --locked --release --bin Toolbox
```

Windows 发布程序默认生成在 `target/release/Toolbox.exe`。首次构建需要下载 Cargo 依赖；依赖已缓存后可在上述命令中增加 `--offline`。

热电偶计算系数在编译时嵌入程序。运行已构建的 EXE 不需要额外附带 `data/`，也不需要 Python、Node.js 或网页脚本。源码构建时必须保留 `data/thermocouple/`。

## 生成 Windows 发布包

在项目根目录使用 PowerShell 执行以下步骤。先退出正在使用构建目录或发布目录中同名 EXE 的旧程序，避免文件被占用。

```powershell
cargo build --locked --release --bin Toolbox
if ($LASTEXITCODE -ne 0) { throw "发布构建失败，已停止打包。" }

New-Item -ItemType Directory -Path 'dist' -Force | Out-Null
Copy-Item -LiteralPath 'target/release/Toolbox.exe' -Destination 'dist/Toolbox.exe' -Force
Copy-Item -LiteralPath 'README.md' -Destination 'dist/README.md' -Force
Copy-Item -LiteralPath 'licenses/PsychroLib-LICENSE.txt' -Destination 'dist/PsychroLib-LICENSE.txt' -Force

Compress-Archive -LiteralPath @(
    'dist/Toolbox.exe',
    'dist/README.md',
    'dist/PsychroLib-LICENSE.txt'
) -DestinationPath 'dist/Toolbox-windows.zip' -Force
```

生成的 `dist/Toolbox-windows.zip` 包含程序、说明和现有第三方声明。这里显式列出打包文件，避免将旧文件或压缩包本身再次打入归档。

```text
dist/
├── Toolbox.exe
├── README.md
├── PsychroLib-LICENSE.txt
└── Toolbox-windows.zip
```

`target/` 与 `dist/` 均由 `.gitignore` 排除。发布附件使用 ZIP 即可，源码仓库保留 `Cargo.toml`、`Cargo.lock`、README、`src/`、`data/` 和 `licenses/`。

## 计算与功能边界

### 数据、精度与状态

- 计算使用 `f64` 双精度浮点数。界面显示会格式化或舍入，不能把显示位数当作实际计量精度；CSV 不按界面显示的小数位截断。
- 不接受 NaN、无穷大和无效量程。模型也会检查适用温区、正值、单调分支和无法表示的数量级；不同模型的有效范围分别判断。
- 各页“计算说明”定义当前采用的公式、单位和正负方向。校准示例值只用于演示，应按实际证书替换；模型规定的修约与界面格式化是两回事。
- 输入只在当前进程内保存，关闭程序后不会恢复；没有证书/标准器命名档案库、重启持久化、Excel 批量导入或 XLSX 校准报表。

### 单位换算

- 温度页面换算的是绝对温度值，拒绝低于 0 K 的输入；温差只使用比例，不能套用温度值的零点偏移。
- 压力换算只改变单位，不自动把表压换成绝压。水柱按 4 °C、汞柱按 0 °C 的约定系数计算，不按现场介质密度或当地重力自动修正。
- `cal/kcal/Btu` 采用国际蒸汽表定义，其中 `1 cal = 4.1868 J`。公制与英制马力、英制与美制加仑分别处理。
- 质量流量 `t/a` 按每年 8000 运行小时计算；美制石油桶按 42 美制加仑，英制桶按 35 英制加仑；历史英制节按 6080 ft/h。
- 浓度的质量比、体积比和质量浓度采用等密度 1000 kg/m³ 基准，滴体积约定为 20 滴/mL。这些结果不能直接用于任意密度的实际物质；当前没有实际密度、摩尔浓度或气体状态输入。
- “传热速度”这一工具名称下计算的是热流密度（功率/面积）。

### 热电偶、热电阻与校准

- 工业热电偶按各分度号自己的曲线温区计算；U 型限于 −200～600 °C。B 型的非正基准热电势处于多值区，不能唯一反算；分段不连续区间也会拒绝不可靠解。
- IEC 60584-1 允差仅对已内置等级数据的型号显示。等级温区和曲线换算温区分别检查，没有允差数据不等于允差为零。
- 工业热电阻共有 21 个预设和 1 个自定义 CVD。Cu10(427) 的 10 Ω 为约 25 °C 标称值，0 °C 的 R₀ 为 9.035 Ω；修改 R₀ 会同步改变计算电阻。
- 铂电阻允差区分绕线式与薄膜式；非 385 铂电阻和自定义 CVD 的等级结果为公式参考值。铜电阻有相应温度允差公式，镍电阻未内置等级允差数据。
- 自定义 CVD 必须在支持范围内形成正值、单调递增的曲线。三点拟合需可独立确定 A/B/C，至少一个校准点应低于 0 °C，不能用退化点组强行求解。
- 标准热电偶固定点输入是实际热电势（mV），不是修正量；直接系数模式限定所选温区，B 型反算限定 ≥50 °C 的分支。参考端补偿仍须符合当前模型的有效范围。
- SPRT 的 Rtp 是水三相点 0.01 °C 电阻。高温分区上限分别为 961.78、660.323、419.527、231.928、156.599、29.765 °C；低温显示区间为 −189.344～0 °C 或 −38.834～0 °C。高低温分区可单独停用，但不能同时停用；银点 d 项仅在对应高温模式启用。
- 热敏电阻的多项式温度用 K、电阻用 Ω，A/B 系数独立拟合，不保证互为精确反函数。当前阶数为 3～6，校准点必须足够且独立；β 模型及多项式模型均不能替代其证书给定的适用条件。

### 压力、湿度与辐射

- 标准器推荐只在内置量程和准确度组合中筛选，必须同时满足覆盖范围及评定判据；它不是设备数据库，也不自动判断具体仪器的其他性能或规程条件。
- 高度差以被检表高于标准器为正。`p标准−p被检 = ρgΔH`，把标准压力移至被检高度的修正量取其相反数。气体高差使用局部恒定密度近似，环境气柱按标准大气估算。
- 气压高度模型覆盖 −1000～86000 m，输入气压为绝对压力；输出是标准大气的位势高度，未计入实际天气，也不是几何海拔换算。
- 湿度环境和湿球模型温区为 −100～100 °C，需满足 0～100 %RH、水气分压小于总压及有效湿球反算范围。非正露/霜点输入按冰面处理，结果分别显示水面露点和适用时的冰面霜点；零湿度没有有限露/霜点。
- 湿度混合比以干空气质量为分母，比湿以湿空气总质量为分母；标准状态含水量按 0 °C、101.325 kPa 表示，不能混用这些定义。
- 辐射模型的发射率须满足 `0 < ε ≤ 1`。有效波长法限制背景温度不高于 200 °C，温差按 0.01 °C 修约后再参与示值修正；Planck 模型假设单波长或平坦波段响应，波长范围为 0.1～100 μm。
- 有效波长模型和 Planck 模型的误差定义不同，应按结果标签区分“真温−模型温度”“亮温−真温”和“修正后−示值”。耳温计多次反射模型假设两表面相互完全可见；一次反射近似可能在等温时仍有截断偏差。

### 统计、不确定度与变送器

- 重复性使用以 n−1 为分母的样本标准差，支持 2～50 个测量值。相对标准偏差为 `s/|均值|×100%`，均值为零时不定义；它与绝对量纲的重复性标准差含义不同。
- 极差法使用 2～9 次测量的两位小数系数表：1.13、1.69、2.06、2.33、2.53、2.70、2.85、2.97；这是标准差估计方法。
- 平方和根用于不相关分量的合成估计；最坏情况绝对值和、最大绝对贡献与平方和根不是同一判据。压力相对误差先乘量程跨度，再统一单位合成。
- 绝对误差保留正负号，相对误差与引用误差分别使用各自的参考分母；分母为零时不定义对应百分误差。
- 不确定度预算表支持顶层 1～20 个分量、每组 1～12 个子分量，递归分组深度上限为 4。各分量先求标准不确定度，再应用灵敏系数；B 类输入是区间半宽。
- 扩展不确定度为 `U=k·uc`，k 必须大于零。修约按 uc、U 的较大值和所选有效位确定小数位，当前最低修约到整数位；修约后 U 由修约后的 uc 乘 k 得到。没有自动计算有效自由度、相关系数或置信水平。
- 变送器输入限定在所设量程内，范围上限必须大于下限；开方使用非负量程比例，不做负区或超量程外推。mA/V/mV 及过程量范围由用户按仪表配置填写，切换信号名称不代表自动换算仪表配置。

### 分度表与 B 样条

- 分度表最多 50,000 行，按显示温标的步长采样并包含终点，预览每页 10 行；表中变化率为有限差分，页面模型提供的解析导数则按对应算法计算。
- B 样条需要 2～500 个 Q 点，x 必须严格递增。均匀的是参数节点，Q 点的 x 可以非等距；若插值后 x 曲线回折，程序会拒绝无法唯一求 y(x) 的输入。
- 自然端点条件施加在参数曲线上，端点 x/y 的二阶参数导数均为零。外推延用端点三次式，仅在 x 的单调分支内有效。
- 样条采样最多 5,000,000 点，范围末端始终包含最大 x，步进须能被当前数值精度分辨。预览只显示前 100 行、每页 10 行，CSV 导出全部采样点。
- 分度表 CSV 使用带 BOM 的 UTF-8，样条 CSV 使用 `x,y` 表头及数值；大规模样条导出在后台进行，可取消，写入失败或取消时不会覆盖已有目标文件。
