# 工具箱 C++ 版

**Toolbox** 是使用 C++17、Win32、Direct2D 和 DirectWrite 编写的 Windows 离线桌面计算工具，包含 **6 个分类、42 个工具、256 项换算单位**。

界面支持窗口缩放、分类折叠与工具搜索，使用系统字体、DPI 适配和 ClearType 文字抗锯齿。默认构建 **64 位单文件 EXE**，同时提供 **Windows 7 SP1 32 位**构建方案。

## 构建与运行

预先配置好完整的 **mingw64 / mingw32** 工具链，包含 C++ 编译组件、静态运行库与 `windres`。`gcc` 和 `windres` 应来自同一套工具链。

以下命令均在 **`cpp_version` 目录**执行。

### 默认构建 64 位

PATH 指向 mingw64，在 PowerShell 中执行：

```powershell
.\build.cmd
```

生成 `dist/x64/Toolbox.exe`，双击即可运行。

### 构建 32 位

将 PATH 切换到 mingw32，再执行：

```powershell
.\build.cmd x86
```

生成 `dist/x86/Toolbox.exe`。脚本会检查 GCC 的目标架构，32 位构建额外使用 `-msse2 -mfpmath=sse -pthread`。

**Windows 7 SP1 32 位方案**使用 GCC 8.1.0、POSIX/DWARF/MSVCRT 的 mingw32 工具链，构建命令同上，处理器须支持 SSE2。该方案尚未完成 Win7 真机验证；仅添加 `-m32` 或使用任意新版 mingw32 不能保证 Win7 兼容。

### 直接使用 GCC

也可以直接编译资源并调用 GCC，无需使用批处理脚本。

**64 位，使用 mingw64：**

```powershell
New-Item -ItemType Directory -Force build, dist/x64 | Out-Null
windres -c 65001 -O coff resources/Toolbox.rc -o build/Toolbox.res.o
gcc "@build.rsp" -O2 -s -o dist/x64/Toolbox.exe
```

**32 位，使用 mingw32：**

```powershell
New-Item -ItemType Directory -Force build, dist/x86 | Out-Null
windres -c 65001 -O coff resources/Toolbox.rc -o build/Toolbox.res.o
gcc "@build.rsp" -O2 -s -msse2 -mfpmath=sse -pthread -o dist/x86/Toolbox.exe
```

`build.rsp` 保存源码清单、C++17 编译参数与链接库；`gcc` 根据 `.cpp` / `.cc` 扩展名编译 C++，通过 `-lstdc++` 显式链接 C++ 标准库。切换架构后须使用对应工具链重新编译资源。

需要调试时，将手动命令中的 `-O2 -s` 换成 `-O0 -g`。普通构建只需要本目录源码和 MinGW 工具链。

## 生成 Windows 发布程序

每次构建直接在所选架构的 `dist` 子目录生成 **一个 EXE**：

| 构建目标 | 发布文件 |
| --- | --- |
| 64 位 | `dist/x64/Toolbox.exe` |
| 32 位 | `dist/x86/Toolbox.exe` |

- **发布时发送对应的 EXE 即可。** C++、GCC 及所需线程运行库采用静态链接，Windows 系统 DLL 由操作系统提供。
- `build/` 仅存放资源编译的中间文件，可删除，下次构建会自动创建。
- 版本信息、程序清单与第三方许可均已嵌入 EXE，运行时无需附带源码、`resources/`、`licenses/` 或 `third_party/`。
- 发布前先退出正在使用目标 EXE 的程序，避免文件被占用。`build/` 和 `dist/` 已由 [.gitignore](.gitignore) 排除。

## 计算与功能边界

### 数值精度与界面状态

- 计算使用 `double` 双精度浮点数。界面格式化与舍入只影响显示，显示的小数位数不代表实际计量精度；CSV 保留可往返还原原始 `double` 的十进制文本。
- 十进制解析与格式化统一使用 double-conversion，界面与 CSV 均展开为普通小数。构建关闭 fast-math 和隐式乘加合并，需要融合乘加的公式显式使用 `std::fma`。
- 校准拟合使用列缩放与两遍重正交化 QR。模型检查有限值、量程、温区、正值及必要的单调性，拒绝无效输入或无法可靠求解的情况。
- 侧栏分类默认收起，可折叠导航；表单与结果随窗口宽度调整。DirectWrite 负责文字排版，Direct2D 使用 ClearType 渲染，图形初始化失败时尝试软件渲染。
- 输入仅在当前进程内保存，关闭程序后不会恢复。当前没有证书档案库、Excel 批量导入或 XLSX 报表功能。
- 校准示例值用于演示，应按实际证书替换；每页“计算说明”给出当前模型的公式、单位与正负方向。

### 单位换算

- 温度换算针对绝对温度值，拒绝低于 0 K 的输入；温差仅使用温标比例，不能套用绝对温度的零点偏移。
- 压力换算仅改变单位，不自动在表压与绝压之间转换。水柱按 4 °C、汞柱按 0 °C 的约定系数计算。
- `cal/kcal/Btu` 采用国际蒸汽表定义，其中 `1 cal = 4.1868 J`。公制与英制马力、英制与美制加仑分别处理。
- 质量流量 `t/a` 按每年 8000 运行小时计算；美制石油桶按 42 美制加仑，英制桶按 35 英制加仑；历史英制节按 6080 ft/h。
- 浓度换算采用 1000 kg/m³ 等密度基准，滴体积约定为 20 滴/mL，不能直接代替任意密度物质的浓度换算；当前没有实际密度或摩尔浓度输入。
- “传热速度”工具计算的是热流密度，即功率除以面积。

### 热电偶、热电阻与校准

- 工业热电偶按各分度号的有效曲线温区计算。U 型限于 −200～600 °C；B 型非正基准热电势不能唯一反算，分段不连续区间也会拒绝不可靠解。
- 等级允差与曲线换算分别检查适用温区，仅显示已内置允差数据的型号；缺少等级数据不表示允差为零。
- 工业热电阻有 21 个预设和 1 个自定义 CVD。Cu10(427) 的 10 Ω 为约 25 °C 标称值，0 °C 的 R₀ 为 9.035 Ω；修改 R₀ 会同步改变计算电阻。
- 铂电阻允差区分绕线式与薄膜式；非 385 铂电阻和自定义 CVD 的等级结果为公式参考值。铜电阻提供相应允差公式，镍电阻未内置等级允差数据。
- 自定义 CVD 在支持范围内须形成正值、单调递增曲线。三点拟合须能独立确定 A/B/C，至少一个校准点低于 0 °C。
- 标准热电偶固定点输入为实际热电势（mV）。直接系数模式受所选温区限制，B 型反算限定在 ≥50 °C 的分支；参考端补偿须符合当前模型的有效范围。
- SPRT 的 Rtp 是水三相点 0.01 °C 电阻。高温分区上限为 961.78、660.323、419.527、231.928、156.599、29.765 °C；低温显示区间为 −189.344～0 °C 或 −38.834～0 °C。高低温分区可分别停用，但不能同时停用；银点 d 项仅在对应高温模式启用。
- SPRT 按子区间启用偏差系数，逆参考多项式初值经正参考函数数值校正；低温 a5/b5 的镓点参与拟合，但不扩大低温页面上限。
- 热敏电阻多项式使用 K 与 Ω，A/B 系数独立拟合，不保证互为精确反函数；阶数为 3～6，校准点须足够且独立。电阻变化率由 B 多项式解析求导，β 模型与多项式模型均须按实际校准条件使用。

### 压力、湿度与辐射

- 标准器推荐仅在内置量程与准确度组合中筛选，须同时满足覆盖范围和评定判据；实际选型仍须结合仪器其他性能与适用规程。
- 压力变送器合成评定的电测项按两端最坏读数计算：读数准确度 / 100 × `max(|输出下限|, |输出上限|)` + 固定误差。固定误差与输出信号使用相同单位，合成扩展不确定度采用 k=2。
- 高度差以被检表高于标准器为正，`p标准−p被检 = ρgΔH`；移至被检高度的压力修正量取其相反数。气体高差采用局部恒定密度近似。
- 气压高度模型覆盖 −1000～86000 m，输入为绝对压力，输出为标准大气的位势高度，未计入实际天气变化。
- 湿度环境与湿球模型温区为 −100～100 °C，要求相对湿度在 0～100 %RH 内、水气分压小于总压。湿球低于模型下限时单项提示，保留其他可计算结果。
- 非正露/霜点输入按冰面处理，结果分别显示水面露点与适用时的冰面霜点；零湿度没有有限露/霜点。混合比以干空气质量为分母，比湿以湿空气总质量为分母；标准状态含水量按 0 °C、101.325 kPa 表示。
- 辐射模型要求 `0 < ε ≤ 1`。有效波长法限制背景温度不高于 200 °C，温差按 0.01 °C 修约后参与示值修正；Planck 模型采用单波长或平坦波段响应，波长范围为 0.1～100 μm。
- 各辐射模型的误差正负方向以结果标签为准。耳温计多次反射模型假设两表面相互完全可见，一次反射近似在等温时也可能存在截断偏差。

### 统计、不确定度与变送器

- 重复性计算支持 2～50 个测量值，样本标准差以 n−1 为分母；相对标准偏差为 `s/|均值|×100%`，均值为零时不定义。
- 极差法适用于 2～9 次测量，d₂ 依次为 1.13、1.69、2.06、2.33、2.53、2.70、2.85、2.97，采用两位小数表值估算标准差。
- 平方和根用于不相关分量的合成估计，最坏情况界限采用绝对值和。压力相对误差先乘量程跨度，再统一单位合成。
- 绝对误差保留正负号；相对误差与引用误差分别使用各自的分母，分母为零时不定义对应百分误差。
- 不确定度预算表支持顶层 1～20 个分量、每组 1～12 个子分量，分组深度上限为 4。分量先换算为标准不确定度，再应用灵敏系数；B 类输入为区间半宽。
- 扩展不确定度为 `U=k·uc`，k 须大于零。按 uc、U 的较大值与所选有效数字确定修约位数，修约后的 U 由修约后的 uc 乘 k 得到；未自动计算有效自由度、相关系数或置信水平。
- 变送器输入须在所设量程内，上限大于下限；开方特性使用非负量程比例。过程量与信号量程由用户按仪表配置填写，切换 mA/V/mV 名称不会自动换算原有配置。

### 分度表与 B 样条

- 分度表最多 50,000 行，按所选温标步长采样并包含终点，预览每页 10 行。表中变化率使用有限差分，页面模型中的解析导数按对应公式计算。
- B 样条需要 2～500 个 Q 点，x 严格递增；均匀的是参数节点，Q 点的 x 可以非等距。插值后 x 曲线若回折，会拒绝无法唯一求 y(x) 的输入。
- 自然端点条件施加在参数曲线上，端点 x/y 的二阶参数导数均为零。外推沿用端点三次式，仅在 x 的单调分支内有效。
- 样条采样最多 5,000,000 点，包含范围末端，步进须能被当前数值精度分辨。预览显示前 100 行、每页 10 行，CSV 导出全部采样点。
- 分度表 CSV 使用带 BOM 的 UTF-8，样条 CSV 使用 `x,y` 表头。导出在后台进行并支持取消；先写入同目录暂存文件，完整写入后再替换目标，失败或取消时保留已有文件。
